Arbana Privacy Policy

Last updated: January 2026

Arbana ("we", "our", or "us") operates a Shopify application that helps merchants increase the visibility of their discounted products by synchronizing selected inventory items to a consumer-facing marketplace.

1. Information We Collect

1.1 Merchant Data

  • Store name and domain
  • Store email address
  • Store ID
  • Currency and location
  • Shopify API access token

1.2 Product & Inventory Data

  • Product titles, descriptions, images
  • Prices and discounts
  • Inventory levels
  • Availability status

1.3 Usage Data

  • Installation and uninstall events
  • Sync logs and error logs
  • API request activity

2. How We Use Your Data

We use merchant data strictly to provide Arbana’s core functionality:

  • Syncing discounted products to the Arbana marketplace
  • Keeping pricing and inventory accurate
  • Providing merchant support
  • Improving service reliability

3. Data Sharing

Product data is shared only with the Arbana consumer marketplace for customer discovery and purchasing. We do not sell or share merchant data with advertisers or brokers.

4. Data Security

We use industry-standard security practices including TLS encryption, secure API authentication, access controls, and monitoring.

5. Data Retention

When you uninstall Arbana, your access token is revoked and your store data is deleted from our systems. Limited logs may be retained temporarily for security and audit purposes.

6. Shopify API Compliance

Arbana operates fully within Shopify’s platform and APIs and does not bypass checkout, billing, or core workflows.

7. Your Rights

You may request access, correction, or deletion of your data at any time.
